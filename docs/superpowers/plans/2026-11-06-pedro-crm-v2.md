# Scout CRM v2.0 Evolution — Publicidades, Metas de Depositantes & Importação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Scout CRM from an influencer prospecting tool into Pedro's complete affiliate operations ERP (.bet.br), adding Financial Advertisements Control, Depositor Goals (CPA tracking), Unified Influencer Profiles, and Spreadsheet Importer/Exporter with Pedro's 87 real leads.

**Architecture:**
1. Data Layer (`server/db/store.js`): Expanded store with in-memory & Supabase support for `influencers`, `campaign_games` (fixed 4 games), `advertisements`, and `deposit_goals`. Seeded with Pedro's real historical data (87 influencers, 17 publicidades, deposit goals).
2. API Layer: New routes `/api/publicidades`, `/api/metas`, `/api/import`, and `/api/influencers/:id/full-profile`.
3. Frontend Layer: Top-level segmented navigation tabs (`🎯 Captação`, `💰 Publicidades`, `🏁 Metas de Depositantes`, `📥 Importador`), with dedicated views, KPI footers, live progress bars, quick "+ Depositantes" modal, and unified profile drawer.

**Tech Stack:** React 19 (Vite), Express.js, TailwindCSS, Lucide-react, Node.js crypto/date utils.

## Global Constraints
- Do not delete or corrupt existing influencer records (100% additive).
- ROI calculation formula: `(retorno - custo_total) / custo_total`. If return is empty/null, display `—` (dash) and NEVER -100%. Unreported publicidades are excluded from overall ROI.
- Games must be fixed to Pedro's 4 games: `Block Win`, `Bubble Win`, `Cust Win`, `Count Masters`.
- Phone numbers must be normalized: digits only with DDD, formatted as `(XX) XXXXX-XXXX`, with direct `wa.me/55...` WhatsApp button.
- All numbers formatted in Brazilian Real (`R$ 1.234,56`) and dates in Brazilian format (`DD/MM/AAAA`).
- Vite build must succeed with 0 compilation errors.
